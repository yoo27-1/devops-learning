## Bandit level 3 - 4

## Level Goal

The password for the next level is stored in a hidden file in the inhere directory.

## Solution

Input the 'find' command.

## Explanation

Since the find command searches files and directories based on conditions, without the conditions it should just display all files within the directory even if hidden. Inputting 'find' displayed the file ...Hiding-From-You which was not there when using ls on the directory.

## What I learned
the find command is able to search for hidden files within directories.
